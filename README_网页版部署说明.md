## 📋 工具简介

这是一个完全免费的在线工具，专门为抖音带货视频创作者设计，可以一键生成适用于以下AI视频生成平台的提示词：

## 🚀 快速部署方法

### 方法一：直接上传到静态网站托管（推荐）

1. **GitHub Pages**（免费）
   - 将 `抖音带货AI视频提示词生成工具_网页版.html` 上传到GitHub仓库
   - 在仓库设置中启用GitHub Pages
   - 访问地址：`https://[你的用户名].github.io/[仓库名]/`

2. **Vercel**（免费）
   - 注册Vercel账号
   - 拖拽HTML文件到Vercel部署界面
   - 自动生成可访问的URL

3. **Netlify**（免费）
   - 注册Netlify账号
   - 拖拽HTML文件部署
   - 获得 `[你的项目名].netlify.app` 域名

### 方法二：自建服务器

```bash
# 1. 安装Node.js和http-server
npm install -g http-server

# 2. 进入工具所在目录
cd /path/to/tool

# 3. 启动服务器
http-server -p 8080

# 4. 访问 http://localhost:8080/抖音带货AI视频提示词生成工具_网页版.html
```

### 方法三：使用Python简单服务器

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

## 🛠️ 自定义修改

### 修改样式
编辑CSS部分中的颜色变量：
```css
:root {
  --primary: #FF3B5C;      /* 主色调 */
  --bg: #0F0F0F;           /* 背景色 */
  --text: #F0F0F0;         /* 文字颜色 */
  /* ... 其他变量 */
}
```

### 添加新品类
在JavaScript的 `CATEGORY_SCENES` 和 `CATEGORY_PAIN_HINTS` 中添加：
```javascript
const CATEGORY_SCENES = {
  // ... 现有品类
  your_new_category: {
    hook: '...',
    pain: '...',
    demo: '...',
    proof: '...',
    cta: '...'
  }
};
```

### 修改提示词模板
编辑 `buildKlingPrompt`、`buildJimengPrompt`、`buildKlingEngPrompt` 函数
